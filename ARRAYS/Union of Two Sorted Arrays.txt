📌 Problem 9: Union of Two Sorted Arrays
❓ What is the question asking?

Given two sorted arrays, return their union.

👉 Union means:

Include all distinct elements.
The result should also be sorted.
Example
Input:
arr1 = [1,2,2,3,4]
arr2 = [2,3,5]

Output:
[1,2,3,4,5]
🪨 Brute Force Approach
💡 Idea
Insert all elements from both arrays into a TreeSet.
TreeSet automatically:
Removes duplicates.
Keeps elements sorted.
💻 Java Code
import java.util.*;

class Main {

    static ArrayList<Integer> union(int arr1[], int arr2[]) {

        TreeSet<Integer> set = new TreeSet<>();

        for(int num : arr1)
            set.add(num);

        for(int num : arr2)
            set.add(num);

        return new ArrayList<>(set);
    }

    public static void main(String args[]) {

        int arr1[] = {1,2,2,3,4};
        int arr2[] = {2,3,5};

        System.out.println(union(arr1, arr2));
    }
}
▶️ Output
[1, 2, 3, 4, 5]
⏱️ Time Complexity
O((n + m) log(n + m))
📦 Space Complexity
O(n + m)
⚡ Optimal Approach (Two Pointers)
💡 Idea

Since both arrays are already sorted, use two pointers.

i → traverses arr1
j → traverses arr2

Compare the elements:

If arr1[i] < arr2[j], add arr1[i].
If arr2[j] < arr1[i], add arr2[j].
If both are equal, add only one and move both pointers.

⚠️ Before adding, check that the last element in the answer is different to avoid duplicates.

🧠 Dry Run
arr1 = [1,2,2,3,4]
arr2 = [2,3,5]
i	j	Compare	Answer
0	0	1 < 2	[1]
1	0	2 = 2	[1,2]
2	1	2 < 3 (duplicate, skip)	[1,2]
3	1	3 = 3	[1,2,3]
4	2	4 < 5	[1,2,3,4]
End	2	Remaining 5	[1,2,3,4,5]

🎉 Final Answer:

[1,2,3,4,5]
💻 Java Code
import java.util.*;

class Main {

    static ArrayList<Integer> union(int arr1[], int arr2[]) {

        ArrayList<Integer> ans = new ArrayList<>();

        int i = 0, j = 0;

        while(i < arr1.length && j < arr2.length) {

            if(arr1[i] <= arr2[j]) {

                if(ans.size() == 0 || ans.get(ans.size() - 1) != arr1[i]) {
                    ans.add(arr1[i]);
                }
                i++;
            }
            else {

                if(ans.size() == 0 || ans.get(ans.size() - 1) != arr2[j]) {
                    ans.add(arr2[j]);
                }
                j++;
            }
        }

        while(i < arr1.length) {

            if(ans.size() == 0 || ans.get(ans.size() - 1) != arr1[i]) {
                ans.add(arr1[i]);
            }
            i++;
        }

        while(j < arr2.length) {

            if(ans.size() == 0 || ans.get(ans.size() - 1) != arr2[j]) {
                ans.add(arr2[j]);
            }
            j++;
        }

        return ans;
    }

    public static void main(String args[]) {

        int arr1[] = {1,2,2,3,4};
        int arr2[] = {2,3,5};

        System.out.println(union(arr1, arr2));
    }
}
▶️ Output
[1, 2, 3, 4, 5]
⏱️ Time Complexity
O(n + m)
📦 Space Complexity
O(n + m)

(The output list is included in the space complexity.)

🎯 Edge Cases
Case 1
arr1 = []
arr2 = [1,2]

Output:
[1,2]
Case 2
arr1 = [1,1,1]
arr2 = [1,1]

Output:
[1]
Case 3
arr1 = [1,2,3]
arr2 = [4,5]

Output:
[1,2,3,4,5]
📝 Interview Tip

This problem teaches the Two Pointer pattern:

i moves through the first sorted array.
j moves through the second sorted array.
Always compare the current elements and move the appropriate pointer.
Skip duplicates before adding to the answer.

This same pattern is used later in Merge Sorted Arrays, 3 Sum, 4 Sum, and many other interview problems.
