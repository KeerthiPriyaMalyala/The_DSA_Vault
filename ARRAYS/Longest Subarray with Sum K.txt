🔹 Longest Subarray with Sum K
❓ What is the question asking?

Given an integer array (can contain positive, negative and zero) and an integer K, return the length of the longest subarray whose sum is exactly K.

Example
Input:
arr = [1,2,3,1,1,1,1,-1,2]
K = 3

Output:
3
🪨 Brute Force Approach
💡 Idea

Generate every possible subarray.

Calculate its sum.

If sum equals K,

Update maximum length.

💻 Java Code
public class Main {

    public static int longestSubarray(int[] arr, int k) {

        int maxLength = 0;

        for (int i = 0; i < arr.length; i++) {

            int sum = 0;

            for (int j = i; j < arr.length; j++) {

                sum += arr[j];

                if (sum == k) {
                    maxLength = Math.max(maxLength, j - i + 1);
                }
            }
        }

        return maxLength;
    }

    public static void main(String[] args) {

        int[] arr = {1,2,3,1,1,1,1,-1,2};

        System.out.println(longestSubarray(arr,3));
    }
}
▶️ Output
3
⏱️ Time Complexity
O(n²)
📦 Space Complexity
O(1)
🟡 Better Approach (Prefix Sum + HashMap)
💡 Idea

Store

Prefix Sum → First Index

Suppose

Current Prefix Sum = sum

We need

sum - previousSum = K

So,

previousSum = sum - K

If

sum - K

already exists in the HashMap,

then the subarray between those indices has sum = K.

Store only the first occurrence of every prefix sum because it gives the longest subarray.

💻 Java Code
import java.util.*;

public class Main {

    public static int longestSubarray(int[] arr, int k) {

        HashMap<Integer, Integer> map = new HashMap<>();

        int sum = 0;
        int maxLength = 0;

        for (int i = 0; i < arr.length; i++) {

            sum += arr[i];

            if (sum == k) {
                maxLength = i + 1;
            }

            if (map.containsKey(sum - k)) {
                maxLength = Math.max(maxLength, i - map.get(sum - k));
            }

            if (!map.containsKey(sum)) {
                map.put(sum, i);
            }
        }

        return maxLength;
    }

    public static void main(String[] args) {

        int[] arr = {1,2,3,1,1,1,1,-1,2};

        System.out.println(longestSubarray(arr,3));
    }
}
▶️ Output
3
⏱️ Time Complexity
O(n)
📦 Space Complexity
O(n)

🎯 Pattern Recognition

Use Prefix Sum + HashMap when:

✅ Array contains negative numbers.
✅ Find longest subarray.
✅ Find subarray with sum = K.
✅ Need O(n) solution.
❌ Don't Use Sliding Window

Example

[2,-1,2]
K = 3

Negative numbers make the window sum unpredictable, so Sliding Window fails.

Use

Prefix Sum + HashMap

⭐ Prefix Sum Formula
Current Prefix Sum = sum

Need:

sum - previousSum = K

Therefore,

previousSum = sum - K

If sum - K exists in the HashMap, then the subarray from (previous index + 1) to current index has sum K.
