🔹 Majority Element-I (LeetCode 169)
❓ What is the question asking?

Given an integer array of size n, return the element that appears more than n/2 times.

It is guaranteed that the majority element exists.

Example
Input:
[2,2,1,1,1,2,2]

Output:
2

Because

2 appears 4 times

n = 7

n/2 = 3

4 > 3 ✅
🪨 Brute Force Approach
💡 Idea

For every element,

Count how many times it appears.

If count > n/2

return it.

💻 Java Code
public class Main {

    public static int majorityElement(int[] arr) {

        int n = arr.length;

        for (int i = 0; i < n; i++) {

            int count = 0;

            for (int j = 0; j < n; j++) {

                if (arr[i] == arr[j])
                    count++;
            }

            if (count > n / 2)
                return arr[i];
        }

        return -1;
    }

    public static void main(String[] args) {

        int[] arr = {2,2,1,1,1,2,2};

        System.out.println(majorityElement(arr));
    }
}
▶️ Output
2
⏱️ Time Complexity
O(n²)
📦 Space Complexity
O(1)
🟡 Better Approach
💡 Idea

Use a HashMap.

Store frequency of every element.
Traverse the map.
Return the element whose frequency is greater than n/2.
💻 Java Code
import java.util.*;

public class Main {

    public static int majorityElement(int[] arr) {

        HashMap<Integer,Integer> map = new HashMap<>();

        for (int num : arr) {
            map.put(num, map.getOrDefault(num,0)+1);
        }

        for (int key : map.keySet()) {

            if (map.get(key) > arr.length / 2)
                return key;
        }

        return -1;
    }

    public static void main(String[] args) {

        int[] arr = {2,2,1,1,1,2,2};

        System.out.println(majorityElement(arr));
    }
}
▶️ Output
2
⏱️ Time Complexity
O(n)
📦 Space Complexity
O(n)
⚡ Optimal Approach (Moore's Voting Algorithm)
💡 Idea

Maintain

candidate
count
Rules

If

count == 0

Choose current element as candidate.

If

current == candidate

Increase count.

Else

Decrease count.

At the end,

candidate is the majority element.

💻 Java Code
public class Main {

    public static int majorityElement(int[] arr) {

        int candidate = 0;
        int count = 0;

        for (int num : arr) {

            if (count == 0) {
                candidate = num;
            }

            if (candidate == num) {
                count++;
            }
            else {
                count--;
            }
        }

        return candidate;
    }

    public static void main(String[] args) {

        int[] arr = {2,2,1,1,1,2,2};

        System.out.println(majorityElement(arr));
    }
}
▶️ Output
2
⏱️ Time Complexity
O(n)
📦 Space Complexity
O(1)

🧠 Why Moore's Voting Works?

Think of it as cancelling votes.

Whenever you see

Majority Element

Every occurrence of a different element cancels one occurrence of the majority element.

Since the majority element appears more than n/2 times, it can never be completely cancelled.

So, the remaining candidate is the majority element.

🎯 Pattern Recognition

Use Moore's Voting Algorithm when the question says:

✅ Find the element occurring more than n/2 times.
✅ Majority element is guaranteed to exist.
✅ Need O(n) time and O(1) space.

Pick New Candidate

⭐ Interview Tip: If the problem does not guarantee that a majority element exists, perform a second pass after Moore's Voting Algorithm to count the candidate's occurrences and verify that it appears more than n/2 times. This extra verification keeps the algorithm correct for all cases. 💖
