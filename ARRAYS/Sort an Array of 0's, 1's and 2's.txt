🔹 Sort an Array of 0's, 1's and 2's
❓ What is the question asking?

Given an array containing only 0's, 1's and 2's, sort it in ascending order.

Example
Input:
[2,0,2,1,1,0]

Output:
[0,0,1,1,2,2]
🪨 Brute Force Approach
💡 Idea
Simply sort the array using Java's built-in sorting method.
💻 Java Code
import java.util.*;

public class Main {

    public static void sortArray(int[] arr) {

        Arrays.sort(arr);
    }

    public static void main(String[] args) {

        int[] arr = {2,0,2,1,1,0};

        sortArray(arr);

        System.out.println(Arrays.toString(arr));
    }
}
▶️ Output
[0, 0, 1, 1, 2, 2]
⏱️ Time Complexity
O(n log n)
📦 Space Complexity
O(1)
🟡 Better Approach
💡 Idea

Count the number of

0's
1's
2's

Then overwrite the array.

💻 Java Code
import java.util.*;

public class Main {

    public static void sortArray(int[] arr) {

        int zero = 0;
        int one = 0;
        int two = 0;

        for (int num : arr) {

            if (num == 0)
                zero++;
            else if (num == 1)
                one++;
            else
                two++;
        }

        int index = 0;

        while (zero-- > 0)
            arr[index++] = 0;

        while (one-- > 0)
            arr[index++] = 1;

        while (two-- > 0)
            arr[index++] = 2;
    }

    public static void main(String[] args) {

        int[] arr = {2,0,2,1,1,0};

        sortArray(arr);

        System.out.println(Arrays.toString(arr));
    }
}
▶️ Output
[0, 0, 1, 1, 2, 2]
⏱️ Time Complexity
O(n)
📦 Space Complexity
O(1)
⚡ Optimal Approach (Dutch National Flag Algorithm)
💡 Idea

Maintain three pointers:

low
mid
high

Initially,

low = 0
mid = 0
high = n-1
Meaning
0 → low-1      = 0's

low → mid-1    = 1's

mid → high     = Unknown

high+1 → n-1   = 2's

Process until

mid <= high
Case 1
arr[mid] == 0

Swap

arr[low]
arr[mid]

Move

low++
mid++
Case 2
arr[mid] == 1

Already in correct position.

Move

mid++
Case 3
arr[mid] == 2

Swap

arr[mid]
arr[high]

Move

high--

❗Do NOT increment mid.

Reason:

The new element that came from high is still unknown.

💻 Java Code
import java.util.*;

public class Main {

    public static void sortArray(int[] arr) {

        int low = 0;
        int mid = 0;
        int high = arr.length - 1;

        while (mid <= high) {

            if (arr[mid] == 0) {

                int temp = arr[low];
                arr[low] = arr[mid];
                arr[mid] = temp;

                low++;
                mid++;
            }

            else if (arr[mid] == 1) {

                mid++;
            }

            else {

                int temp = arr[mid];
                arr[mid] = arr[high];
                arr[high] = temp;

                high--;
            }
        }
    }

    public static void main(String[] args) {

        int[] arr = {2,0,2,1,1,0};

        sortArray(arr);

        System.out.println(Arrays.toString(arr));
    }
}
▶️ Output
[0, 0, 1, 1, 2, 2]
⏱️ Time Complexity
O(n)
📦 Space Complexity
O(1)

1	1	4	0 0 2 1 1 2

2	3	3	0 0 1 1 2 2

🧠 Memory Trick
0 → Swap with low
    low++
    mid++

1 → Just mid++

2 → Swap with high
    high--
    (Don't move mid)
⭐ Golden Rule

When you swap with high, never increment mid because the element swapped from the end has not been processed yet. This is the most common interview mistake. 💖
