🌟 Problem 1: Largest Element in an Array
❓ What is the question asking?

Given an array, return the largest element present in it.

Example
Input:
[2,5,1,3,0]

Output:
5
🪨 Brute Force Approach
💡 Idea

Sort the array.

The last element after sorting will be the largest.

Example

Before:
2 5 1 3 0

After Sorting:
0 1 2 3 5

Largest = 5
💻 Java Code
import java.util.*;

class Main {

    static int largest(int arr[]) {
        Arrays.sort(arr);
        return arr[arr.length - 1];
    }

    public static void main(String args[]) {

        int arr[] = {2,5,1,3,0};

        System.out.println(largest(arr));
    }
}
▶️ Output
5
⏱️ Time Complexity
O(n log n)
📦 Space Complexity
O(1)
⚡ Optimal Approach
💡 Idea

No need to sort.

Keep one variable max.

Traverse the array once.

Whenever a bigger element is found, update max.

At the end, max is the answer.

🧠 Dry Run
Array:
2 5 1 3 0

max = 2

5 > 2
max = 5

1 > 5 ❌

3 > 5 ❌

0 > 5 ❌

Answer = 5
💻 Java Code
class Main {

    static int largest(int arr[]) {

        int max = arr[0];

        for(int i = 1; i < arr.length; i++) {

            if(arr[i] > max) {
                max = arr[i];
            }
        }

        return max;
    }

    public static void main(String args[]) {

        int arr[] = {2,5,1,3,0};

        System.out.println(largest(arr));
    }
}
▶️ Output
5
⏱️ Time Complexity
O(n)
📦 Space Complexity
O(1)
