📌 Problem 3: Check if the Array is Sorted
❓ What is the question asking?

Given an array, check whether it is sorted in non-decreasing order.

If sorted → return true
Otherwise → return false
Example
Input:
[1, 2, 2, 3, 4]

Output:
true
Input:
[1, 3, 2, 4]

Output:
false
🪨 Brute Force Approach
💡 Idea

Compare every element with every element after it.

If you ever find a smaller element after a larger one, the array is not sorted.

💻 Java Code
class Main {

    static boolean isSorted(int arr[]) {

        for(int i = 0; i < arr.length; i++) {

            for(int j = i + 1; j < arr.length; j++) {

                if(arr[i] > arr[j]) {
                    return false;
                }
            }
        }

        return true;
    }

    public static void main(String args[]) {

        int arr[] = {1,2,2,3,4};

        System.out.println(isSorted(arr));
    }
}
▶️ Output
true
⏱️ Time Complexity
O(n²)
📦 Space Complexity
O(1)
⚡ Optimal Approach
💡 Idea

A sorted array satisfies:

arr[i] <= arr[i + 1]

Traverse the array once.

If at any point:

arr[i] > arr[i + 1]

return false.

Otherwise, return true.

🧠 Dry Run
Array:
1 2 2 3 4

1 <= 2 ✅
2 <= 2 ✅
2 <= 3 ✅
3 <= 4 ✅

Answer = true

Example 2

Array:
1 3 2 4

1 <= 3 ✅
3 <= 2 ❌

Answer = false
💻 Java Code
class Main {

    static boolean isSorted(int arr[]) {

        for(int i = 0; i < arr.length - 1; i++) {

            if(arr[i] > arr[i + 1]) {
                return false;
            }
        }

        return true;
    }

    public static void main(String args[]) {

        int arr[] = {1,2,2,3,4};

        System.out.println(isSorted(arr));
    }
}
▶️ Output
true
⏱️ Time Complexity
O(n)
📦 Space Complexity
O(1)
🎯 Edge Cases
Case 1
Input:
[5]

Output:
true

(Single element array is always sorted.)

Case 2
Input:
[2,2,2,2]

Output:
true

(Equal elements are allowed.)

Case 3
Input:
[5,4,3]

Output:
false
📝 Interview Tip

Always remember:

Sorted (Non-decreasing) means:

arr[i] <= arr[i + 1]

Not:

arr[i] < arr[i + 1]

Equal elements are allowed.
