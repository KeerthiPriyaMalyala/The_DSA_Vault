1470. Shuffle the Array
❓ What is the question asking?

You are given:

An array nums of size 2n.
The first half contains x values.
The second half contains y values.
nums = [x1,x2,...,xn,y1,y2,...,yn]

You have to rearrange it as:

[x1,y1,x2,y2,...,xn,yn]
Example 1
nums = [2,5,1,3,4,7]
n = 3

Split the array:

x = [2,5,1]

y = [3,4,7]

Now place them alternately:

2,3,5,4,1,7

Output:

[2,3,5,4,1,7]
Example 2
nums = [1,2,3,4,4,3,2,1]
n = 4

Output:

[1,4,2,3,3,2,4,1]
🪨 Brute Force Approach
💡 Idea

Create a new array ans of size 2n.

Use:

i → points to first half (x)
j → points to second half (y)
k → points to answer array

Store:

ans[k] = nums[i]
ans[k+1] = nums[j]

Repeat until all elements are used.

💻 Java Code
class Node {
    int data;
    Node left, right;

    Node(int data) {
        this.data = data;
        left = right = null;
    }
}

public class Main {

    public static int[] shuffle(int[] nums, int n) {

        int[] ans = new int[2 * n];

        int i = 0;
        int j = n;
        int k = 0;

        while (i < n && j < 2 * n) {

            ans[k++] = nums[i++];
            ans[k++] = nums[j++];
        }

        return ans;
    }

    public static void main(String[] args) {

        int[] nums = {2,5,1,3,4,7};

        int[] ans = shuffle(nums, 3);

        System.out.print("Output: ");

        for (int x : ans) {
            System.out.print(x + " ");
        }
    }
}
▶️ Output
Output:
2 3 5 4 1 7
⏱️ Time Complexity
O(n)
📦 Space Complexity
O(n)
⚡ Optimal Approach
💡 Idea

For this problem, the above solution is already optimal.

Why?

Every element must be visited at least once.
We need to return a new shuffled array.
Therefore:
Time cannot be better than O(n).
Extra space is O(n) because the answer array itself is required.

So there is no better practical approach for this problem.

🧠 Dry Run

Input:

nums = [2,5,1,3,4,7]

n = 3

Initially:

i = 0
j = 3
k = 0

ans = [_,_,_,_,_,_]
Iteration 1
ans[0] = nums[0] = 2

ans = [2,_,_,_,_,_]

ans[1] = nums[3] = 3

ans = [2,3,_,_,_,_]

Now:

i = 1
j = 4
k = 2
Iteration 2
ans[2] = nums[1] = 5

ans = [2,3,5,_,_,_]

ans[3] = nums[4] = 4

ans = [2,3,5,4,_,_]

Now:

i = 2
j = 5
k = 4
Iteration 3
ans[4] = nums[2] = 1

ans = [2,3,5,4,1,_]

ans[5] = nums[5] = 7

ans = [2,3,5,4,1,7]

Loop ends.

Final Answer:

[2,3,5,4,1,7]
🎯 What you learn from this problem
✅ Splitting an array into two halves
✅ Using multiple pointers (i, j, k)
✅ Creating a new array while traversing the original array once
✅ Alternating elements from two different sections of an array
