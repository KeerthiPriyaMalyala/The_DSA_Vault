605. Can Place Flowers
❓ What is the question asking?

You are given an array where:

1 → Plot already has a flower 🌸
0 → Empty plot 🌱

You need to check whether you can plant n new flowers without placing flowers in adjacent plots.

Return:

true → If possible
false → Otherwise
Example
flowerbed = [1,0,0,0,1]
n = 1

Output = true
🪨 Brute Force Approach
💡 Idea

Try planting a flower at every empty plot.

For each position:

Check left neighbor.
Check right neighbor.
If both are empty (or don't exist), plant a flower.
Count planted flowers.
💻 Java Code
class Solution {
    public boolean canPlaceFlowers(int[] flowerbed, int n) {

        int count = 0;

        for (int i = 0; i < flowerbed.length; i++) {

            if (flowerbed[i] == 0) {

                boolean left = (i == 0) || (flowerbed[i - 1] == 0);
                boolean right = (i == flowerbed.length - 1) || (flowerbed[i + 1] == 0);

                if (left && right) {
                    flowerbed[i] = 1;
                    count++;
                }
            }
        }

        return count >= n;
    }
}
▶️ Output
Input:
flowerbed = [1,0,0,0,1]
n = 1

Output:
true
⏱ Time Complexity

O(n)

📦 Space Complexity

O(1)

⚡ Optimal Approach (Greedy)
💡 Idea

This is already the optimal solution.

At every empty plot:

✅ Left is empty (or boundary)

✅ Right is empty (or boundary)

➡️ Plant immediately.

Why?

Because planting as early as possible never reduces future possibilities. This is a Greedy decision.

💻 Java Code
class Solution {
    public boolean canPlaceFlowers(int[] flowerbed, int n) {

        int count = 0;

        for (int i = 0; i < flowerbed.length; i++) {

            if (flowerbed[i] == 0) {

                boolean left = (i == 0) || (flowerbed[i - 1] == 0);
                boolean right = (i == flowerbed.length - 1) || (flowerbed[i + 1] == 0);

                if (left && right) {

                    flowerbed[i] = 1;
                    count++;

                    if (count >= n)
                        return true;
                }
            }
        }

        return count >= n;
    }
}

📝 Key Notes ⭐
✅ When can we plant?

A flower can be planted if:

Current == 0

AND

Left is 0 (or boundary)

AND

Right is 0 (or boundary)
✅ Boundary Conditions

For the first index:

i == 0

Treat the left side as empty.

For the last index:

i == flowerbed.length - 1

Treat the right side as empty.

✅ Greedy Choice

Whenever a valid empty plot is found:

➡️ Plant immediately.

This never blocks a better future placement.

🎯 Interview Tip

The key observation is to check three positions:

Left neighbor
Current plot
Right neighbor

If all are effectively empty (considering boundaries), plant the flower. This greedy approach is both correct and optimal, running in O(n) time with O(1) extra space. 💖
