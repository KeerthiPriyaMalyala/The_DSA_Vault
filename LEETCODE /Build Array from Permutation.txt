1920. Build Array from Permutation
❓ What is the question asking?

You are given an array nums which is a permutation.

A permutation means:

Numbers are unique.
Numbers range from 0 to n-1.

You have to create a new array ans such that:

ans[i] = nums[ nums[i] ]

That means:

Take nums[i].
Use that value as an index.
Store the value present at that index into ans[i].
Example
nums = [0,2,1,5,3,4]

Let's build ans.

i	nums[i]	nums[nums[i]]	ans[i]
0	0	nums[0]=0	0
1	2	nums[2]=1	1
2	1	nums[1]=2	2
3	5	nums[5]=4	4
4	3	nums[3]=5	5
5	4	nums[4]=3	3

Final answer:

[0,1,2,4,5,3]
🪨 Brute Force Approach
💡 Idea

Create another array.

For every index:

ans[i] = nums[ nums[i] ]

Return ans.

This is actually the standard and simplest solution.

💻 Java Code
class Node {
    int data;
    Node left, right;

    Node(int data) {
        this.data = data;
        left = right = null;
    }
}

public class Main {

    public static int[] buildArray(int[] nums) {

        int n = nums.length;
        int[] ans = new int[n];

        for (int i = 0; i < n; i++) {
            ans[i] = nums[nums[i]];
        }

        return ans;
    }

    public static void main(String[] args) {

        int[] nums = {0, 2, 1, 5, 3, 4};

        int[] ans = buildArray(nums);

        System.out.print("Output: ");

        for (int x : ans) {
            System.out.print(x + " ");
        }
    }
}
▶️ Output
Output:
0 1 2 4 5 3
⏱️ Time Complexity
O(n)
📦 Space Complexity
O(n)
⚡ Optimal Approach (In-place)
💡 Idea

Can we avoid using another array?

Yes! Since every value is between 0 and n-1, we can temporarily store both the old and new values in the same array.

Encoding:

nums[i] = nums[i] + n * (nums[nums[i]] % n)

Later, decode:

nums[i] = nums[i] / n

This works because:

nums[i] % n gives the original value (even after encoding).
Integer division by n extracts the new value.
💻 Java Code
class Node {
    int data;
    Node left, right;

    Node(int data) {
        this.data = data;
        left = right = null;
    }
}

public class Main {

    public static int[] buildArray(int[] nums) {

        int n = nums.length;

        for (int i = 0; i < n; i++) {
            nums[i] = nums[i] + n * (nums[nums[i]] % n);
        }

        for (int i = 0; i < n; i++) {
            nums[i] = nums[i] / n;
        }

        return nums;
    }

    public static void main(String[] args) {

        int[] nums = {0, 2, 1, 5, 3, 4};

        int[] ans = buildArray(nums);

        System.out.print("Output: ");

        for (int x : ans) {
            System.out.print(x + " ");
        }
    }
}
▶️ Output
Output:
0 1 2 4 5 3
⏱️ Time Complexity
O(n)
📦 Space Complexity
O(1)
