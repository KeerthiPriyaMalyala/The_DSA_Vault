485. Max Consecutive Ones
❓ What is the question asking?

You are given a binary array containing only:

0
1

Find the maximum number of consecutive (continuous) 1s.

Example 1
nums = [1,1,0,1,1,1]

There are two groups of 1s:

1 1

Length = 2

and

1 1 1

Length = 3

Maximum =

3
Example 2
nums = [1,0,1,1,0,1]

Groups:

1

Length = 1

1 1

Length = 2

1

Length = 1

Maximum

2
🪨 Brute Force Approach
💡 Idea

For every index:

If it is 1,
Count consecutive 1s until a 0 appears.
Store the maximum count.
💻 Java Code
class Node {
    int data;
    Node left, right;

    Node(int data) {
        this.data = data;
    }
}

public class Main {

    public static int findMaxConsecutiveOnes(int[] nums) {

        int max = 0;

        for (int i = 0; i < nums.length; i++) {

            int count = 0;

            for (int j = i; j < nums.length; j++) {

                if (nums[j] == 1)
                    count++;
                else
                    break;
            }

            if (count > max)
                max = count;
        }

        return max;
    }

    public static void main(String[] args) {

        int[] nums = {1,1,0,1,1,1};

        System.out.println(findMaxConsecutiveOnes(nums));
    }
}
▶️ Output
3
⏱️ Time Complexity
O(n²)
📦 Space Complexity
O(1)
⚡ Optimal Approach
💡 Idea

We only need one traversal.

Maintain:

count → current consecutive 1s
maxCount → maximum consecutive 1s found

Rules:

If current element is 1
Increase count
Update maxCount
If current element is 0
Reset count to 0
💻 Java Code
class Node {
    int data;
    Node left, right;

    Node(int data) {
        this.data = data;
    }
}

public class Main {

    public static int findMaxConsecutiveOnes(int[] nums) {

        int count = 0;
        int maxCount = 0;

        for (int i = 0; i < nums.length; i++) {

            if (nums[i] == 1) {

                count++;

                if (count > maxCount)
                    maxCount = count;

            } else {

                count = 0;
            }
        }

        return maxCount;
    }

    public static void main(String[] args) {

        int[] nums = {1,1,0,1,1,1};

        System.out.println("Maximum Consecutive Ones = " + findMaxConsecutiveOnes(nums));
    }
}
▶️ Output
Maximum Consecutive Ones = 3
⏱️ Time Complexity
O(n)
📦 Space Complexity
O(1)

🧠 Interview Tip

Don't wait until the end to find the maximum.

Whenever you increase count, immediately update:

maxCount = Math.max(maxCount, count);

This keeps the solution simple and efficient.

🧠 Pattern Learned

This problem introduces the Counting/Streak Pattern.

The same idea is used in problems like:

✅ Longest Increasing Subarray
✅ Longest Continuous Sequence
✅ Longest Consecutive Characters in a String
✅ Maximum Consecutive Ones II & III

The general pattern is:

if (condition is satisfied) {
    count++;
    maxCount = Math.max(maxCount, count);
} else {
    count = 0;
}
