941. Valid Mountain Array
❓ What is the question asking?

You are given an integer array arr.

Return:

✅ true if it forms a mountain
❌ false otherwise

A valid mountain must satisfy:

Length ≥ 3
First, numbers should strictly increase
Then, numbers should strictly decrease
There should be exactly one peak
The peak cannot be the first or last element
Example 1
arr = [2,1]

Length is less than 3.

Output

false
Example 2
arr = [3,5,5]

Here,

5 == 5

Not strictly increasing.

Output

false
Example 3
arr = [0,3,2,1]

Increasing:

0 → 3

Decreasing:

3 → 2 → 1

Output

true
🪨 Brute Force Approach
💡 Idea

Find the peak.

Then verify:

Left side is strictly increasing.
Right side is strictly decreasing.
💻 Java Code
class Node {
    int data;
    Node left, right;

    Node(int data) {
        this.data = data;
    }
}

public class Main {

    public static boolean validMountainArray(int[] arr) {

        int n = arr.length;

        if (n < 3)
            return false;

        int peak = 0;

        for (int i = 1; i < n; i++) {
            if (arr[i] > arr[peak])
                peak = i;
        }

        if (peak == 0 || peak == n - 1)
            return false;

        for (int i = 0; i < peak; i++) {
            if (arr[i] >= arr[i + 1])
                return false;
        }

        for (int i = peak; i < n - 1; i++) {
            if (arr[i] <= arr[i + 1])
                return false;
        }

        return true;
    }

    public static void main(String[] args) {

        int[] arr = {0,3,2,1};

        System.out.println(validMountainArray(arr));
    }
}
▶️ Output
true
⏱️ Time Complexity
O(n)
📦 Space Complexity
O(1)
⚡ Optimal Approach (One Pointer)
💡 Idea

Imagine climbing a mountain.

Step 1

Keep moving up while the next element is greater.

1 2 4 7
        ↑
Step 2

Now keep moving down while the next element is smaller.

7 5 3 1
↑

Finally,

If we reach the last element exactly,

it's a mountain.

Otherwise,

it's not.

💻 Java Code
class Node {
    int data;
    Node left, right;

    Node(int data) {
        this.data = data;
    }
}

public class Main {

    public static boolean validMountainArray(int[] arr) {

        int n = arr.length;

        if (n < 3)
            return false;

        int i = 0;

        // Climb up
        while (i + 1 < n && arr[i] < arr[i + 1]) {
            i++;
        }

        // Peak cannot be first or last
        if (i == 0 || i == n - 1)
            return false;

        // Climb down
        while (i + 1 < n && arr[i] > arr[i + 1]) {
            i++;
        }

        return i == n - 1;
    }

    public static void main(String[] args) {

        int[] arr = {0,3,2,1};

        System.out.println(validMountainArray(arr));
    }
}
▶️ Output
true
⏱️ Time Complexity
O(n)
📦 Space Complexity
O(1)

🧠 Interview Tip

The most common mistakes are:

❌ Allowing equal adjacent values.

1 2 2 1

Not valid because:

2 == 2

The increase/decrease must be strict.

❌ Peak at the first element

5 4 3

No increasing part.

❌ Peak at the last element

1 2 3

No decreasing part.

🧠 Pattern Learned

This problem teaches the Peak Traversal Pattern.

The idea is:

Traverse while a condition is increasing.
Validate the turning point (peak).
Traverse while a condition is decreasing.
Check whether you reached the end.

This pattern appears in many problems involving:

✅ Mountain arrays
✅ Peak element detection
✅ Bitonic arrays
✅ Increasing-then-decreasing sequences
