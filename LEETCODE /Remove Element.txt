27. Remove Element
❓ What is the question asking?

You are given:

An integer array nums
A value val

You have to:

Remove all occurrences of val
Do not create a new array (modify the same array)
Return the number of remaining elements (k)

👉 The first k elements should contain all elements that are not equal to val.

The elements after k do not matter.

Example 1
nums = [3,2,2,3]
val = 3

Remove all 3s.

Remaining elements:

[2,2]

So,

k = 2

The array may become

[2,2,_,_]

(The last two positions can contain anything.)

Example 2
nums = [0,1,2,2,3,0,4,2]
val = 2

Remove every 2.

Remaining elements:

[0,1,3,0,4]

Return

k = 5
🪨 Brute Force Approach
💡 Idea

Create another array.

Copy only the elements that are not equal to val.

Then copy them back into the original array.

Finally return the count.

💻 Java Code
class Node {
    int data;
    Node left, right;

    Node(int data) {
        this.data = data;
        left = right = null;
    }
}

public class Main {

    public static int removeElement(int[] nums, int val) {

        int[] temp = new int[nums.length];

        int k = 0;

        for (int i = 0; i < nums.length; i++) {

            if (nums[i] != val) {
                temp[k++] = nums[i];
            }
        }

        for (int i = 0; i < k; i++) {
            nums[i] = temp[i];
        }

        return k;
    }

    public static void main(String[] args) {

        int[] nums = {3,2,2,3};

        int k = removeElement(nums,3);

        System.out.println("k = " + k);

        System.out.print("Array: ");

        for(int i=0;i<k;i++){
            System.out.print(nums[i]+" ");
        }
    }
}
▶️ Output
k = 2
Array: 2 2
⏱️ Time Complexity
O(n)
📦 Space Complexity
O(n)
⚡ Optimal Approach (Two Pointers)
💡 Idea

We don't need another array.

Keep a pointer k that tells us where the next valid element should be placed.

Loop through the array:

If nums[i] != val
Copy it to nums[k]
Increase k

Finally return k.

Example
nums = [3,2,2,3]
val = 3
k = 0

i = 0
3 == val
Skip

-----------------

i = 1
2 != val

nums[0] = 2

[2,2,2,3]

k = 1

-----------------

i = 2
2 != val

nums[1] = 2

[2,2,2,3]

k = 2

-----------------

i = 3
3 == val

Skip

Return

k = 2
💻 Java Code
class Node {
    int data;
    Node left, right;

    Node(int data) {
        this.data = data;
        left = right = null;
    }
}

public class Main {

    public static int removeElement(int[] nums, int val) {

        int k = 0;

        for (int i = 0; i < nums.length; i++) {

            if (nums[i] != val) {
                nums[k] = nums[i];
                k++;
            }
        }

        return k;
    }

    public static void main(String[] args) {

        int[] nums = {3,2,2,3};

        int k = removeElement(nums,3);

        System.out.println("k = " + k);

        System.out.print("Modified Array: ");

        for(int i=0;i<k;i++){
            System.out.print(nums[i]+" ");
        }
    }
}
▶️ Output
k = 2
Modified Array: 2 2
⏱️ Time Complexity
O(n)
📦 Space Complexity
O(1)
🧠 Dry Run

Input

nums = [0,1,2,2,3,0,4,2]
val = 2

Initially

k = 0
i	nums[i]	Action	Array (important part)	k
0	0	Copy	[0]	1
1	1	Copy	[0,1]	2
2	2	Skip	[0,1]	2
3	2	Skip	[0,1]	2
4	3	Copy	[0,1,3]	3
5	0	Copy	[0,1,3,0]	4
6	4	Copy	[0,1,3,0,4]	5
7	2	Skip	[0,1,3,0,4]	5

Return

k = 5

First five elements:

[0,1,3,0,4]
🎯 What you learn from this problem
✅ In-place array modification
✅ Two Pointer technique (i and k)
✅ Overwriting unwanted elements
✅ Returning the count of valid elements instead of creating a new array
🧠 Interview Tip

Many beginners think they need to delete elements from the array.

You don't.

Just move all valid elements to the front and return how many valid elements (k) there are. The remaining elements are ignored.
