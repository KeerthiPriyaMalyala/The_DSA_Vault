384. Shuffle an Array
❓ What is the question asking?

Design a class that supports three operations:

Store the original array.
reset() → Return the original array.
shuffle() → Return a random permutation of the array.

Every possible permutation should be equally likely.

🪨 Brute Force Approach
💡 Idea
Copy all elements into a list.
Repeatedly pick a random element.
Remove it from the list and place it into the answer array.
⏱️ Time Complexity

O(n²)

(Removing from an ArrayList is O(n))

📦 Space Complexity

O(n)

⚡ Optimal Approach (Fisher–Yates Shuffle)
💡 Idea

Start from the beginning.

For every index i:

Randomly choose an index between i and n-1.
Swap them.

This guarantees every permutation is equally likely.

🧠 Dry Run
Input
nums = [1,2,3]

Initially

[1,2,3]
i = 0

Suppose random index = 2

Swap

[3,2,1]
i = 1

Random index = 1

Swap

[3,2,1]
i = 2

Random index = 2

Swap

[3,2,1]

Possible output

[3,2,1]

Next time it may become

[2,3,1]

or

[1,3,2]

Every permutation has the same probability.

💻 Java Code
import java.util.Random;

class Solution {

    private int[] original;
    private Random random;

    public Solution(int[] nums) {
        original = nums.clone();
        random = new Random();
    }

    public int[] reset() {
        return original.clone();
    }

    public int[] shuffle() {

        int[] shuffled = original.clone();

        for (int i = 0; i < shuffled.length; i++) {

            int j = i + random.nextInt(shuffled.length - i);

            int temp = shuffled[i];
            shuffled[i] = shuffled[j];
            shuffled[j] = temp;
        }

        return shuffled;
    }
}
▶️ Example
Solution obj = new Solution(new int[]{1,2,3});

System.out.println(Arrays.toString(obj.shuffle()));
// [2,1,3]

System.out.println(Arrays.toString(obj.shuffle()));
// [3,1,2]

System.out.println(Arrays.toString(obj.reset()));
// [1,2,3]
⏱️ Time Complexity
Constructor

O(n)

(copying the array)

reset()

O(n)

(cloning the original array)

shuffle()

O(n)

(one traversal)

📦 Space Complexity

O(n)

(for storing the original array and creating a shuffled copy)

📝 Key Interview Insight
Do not randomly swap any two indices repeatedly. That does not guarantee all permutations are equally likely.
Fisher–Yates ensures uniform randomness.
At index i, choose a random index only from the remaining unshuffled part (i to n-1).
Clone the original array before shuffling so that reset() can always return the original configuration.
🎯 Pattern
✅ Randomization
✅ Fisher–Yates Shuffle
✅ Simulation
🔑 Quick Revision

For every index i:

Choose random j in [i, n-1]

Swap(nums[i], nums[j])

Repeat until the end.

Final Complexity
⏱️ Constructor: O(n)
⏱️ reset(): O(n)
⏱️ shuffle(): O(n)
📦 Space: O(n)
