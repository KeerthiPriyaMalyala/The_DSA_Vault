83. Move Zeroes
❓ What is the question asking?

Given an array nums, move all 0's to the end of the array.

Conditions
✅ Do it in-place (don't create another array).
✅ Maintain the relative order of non-zero elements.
Example 1
nums = [0,1,0,3,12]

Move all non-zero numbers to the front:

1 3 12

Fill the remaining places with 0:

[1,3,12,0,0]
Example 2
nums = [0]

Output

[0]
🪨 Brute Force Approach
💡 Idea
Create another array.
Copy all non-zero elements.
Fill the remaining positions with 0.
Copy the result back to the original array.
💻 Java Code
class Node {
    int data;
    Node left, right;

    Node(int data) {
        this.data = data;
        left = right = null;
    }
}

public class Main {

    public static void moveZeroes(int[] nums) {

        int[] temp = new int[nums.length];

        int k = 0;

        for (int i = 0; i < nums.length; i++) {

            if (nums[i] != 0) {
                temp[k++] = nums[i];
            }
        }

        while (k < nums.length) {
            temp[k++] = 0;
        }

        for (int i = 0; i < nums.length; i++) {
            nums[i] = temp[i];
        }
    }

    public static void main(String[] args) {

        int[] nums = {0,1,0,3,12};

        moveZeroes(nums);

        System.out.print("Output: ");

        for (int x : nums) {
            System.out.print(x + " ");
        }
    }
}
▶️ Output
Output:
1 3 12 0 0
⏱️ Time Complexity
O(n)
📦 Space Complexity
O(n)
⚡ Optimal Approach (Two Pointers)
💡 Idea

Keep a pointer k that tells us where the next non-zero element should be placed.

Step 1

Move every non-zero element to the front.

Step 2

Fill the remaining positions with 0.

No extra array is needed.

💻 Java Code
class Node {
    int data;
    Node left, right;

    Node(int data) {
        this.data = data;
        left = right = null;
    }
}

public class Main {

    public static void moveZeroes(int[] nums) {

        int k = 0;

        // Move all non-zero elements to the front
        for (int i = 0; i < nums.length; i++) {

            if (nums[i] != 0) {
                nums[k] = nums[i];
                k++;
            }
        }

        // Fill remaining positions with zero
        while (k < nums.length) {
            nums[k] = 0;
            k++;
        }
    }

    public static void main(String[] args) {

        int[] nums = {0,1,0,3,12};

        moveZeroes(nums);

        System.out.print("Output: ");

        for (int x : nums) {
            System.out.print(x + " ");
        }
    }
}
▶️ Output
Output:
1 3 12 0 0
⏱️ Time Complexity
O(n)
📦 Space Complexity
O(1)
🧠 Dry Run

Input

nums = [0,1,0,3,12]

Initially

k = 0
i	nums[i]	Action	Array	k
0	0	Skip	[0,1,0,3,12]	0
1	1	Copy to nums[0]	[1,1,0,3,12]	1
2	0	Skip	[1,1,0,3,12]	1
3	3	Copy to nums[1]	[1,3,0,3,12]	2
4	12	Copy to nums[2]	[1,3,12,3,12]	3

Now k = 3.

Fill the remaining positions with 0.

nums[3] = 0
nums[4] = 0

Final array

[1,3,12,0,0]
🎯 What you learn from this problem
✅ Two Pointer (Write Pointer) technique
✅ In-place array modification
✅ Preserving the order of non-zero elements
✅ Filling the remaining positions after processing
💡 Even Better Interview Approach (Single Pass with Swapping)

The previous optimal solution writes every non-zero element, even if it's already in the correct place. A commonly preferred interview solution uses swapping:

public static void moveZeroes(int[] nums) {

    int k = 0;

    for (int i = 0; i < nums.length; i++) {

        if (nums[i] != 0) {

            int temp = nums[i];
            nums[i] = nums[k];
            nums[k] = temp;

            k++;
        }
    }
}
Why is this nice?

For nums = [0,1,0,3,12]

i = 1  -> Swap 1 with 0
[1,0,0,3,12]

i = 3  -> Swap 3 with 0
[1,3,0,0,12]

i = 4  -> Swap 12 with 0
[1,3,12,0,0]

No second loop is needed, and it still runs in:

⏱️ Time Complexity: O(n)
📦 Space Complexity: O(1)
