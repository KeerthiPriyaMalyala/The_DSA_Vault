969. Pancake Sorting
❓ What is the question asking?

You are given an array.

You cannot swap elements.

You have only one operation:

Choose a value k

Reverse arr[0...k-1]

(i.e., reverse only the first k elements.)

Your task is to sort the array using these pancake flips.

Return the sequence of k values used for the flips.

🍽️ Pancake Flip

Suppose

arr = [3,2,4,1]

Choose

k = 3

Reverse first 3 elements

Before

3 2 4 | 1

↓

After

4 2 3 | 1

Result

[4,2,3,1]
📌 Important Points

✅ You can only reverse the prefix of the array.

✅ You cannot reverse the middle part.

❌ Not allowed

Reverse

2 4 1

✅ Allowed

Reverse

3 2 4

because it starts from index 0.

🎯 Goal

Sort the array

Ascending Order

Return

[k1,k2,k3...]

NOT the sorted array.

💡 Main Idea

For every largest element:

Largest Element

↓

Bring it to Front

↓

Flip Entire Unsorted Part

↓

Largest reaches Correct Position

Repeat until the array becomes sorted.

📖 Example

Input

[3,2,4,1]

Largest

4

Bring

4

to front

↓

Flip whole array

↓

4

goes to last position.

Now repeat for

3

then

2
🪨 Brute Force Approach
💡 Idea

Try different pancake flips until the array becomes sorted.

(Not practical and not used.)

⏱️ Time Complexity
Very High
📦 Space Complexity
O(1)
⚡ Optimal Approach
💡 Idea

For every position from the end:

Find the largest element in the unsorted part.
If it is already in the correct position, continue.
Otherwise:
Flip it to the front.
Flip the whole unsorted part.
Store both flip sizes (k values).

Repeat until the array is sorted.

▶️ Output

For

[3,2,4,1]

Possible answer

[3,4,2,3,2]

or

[4,2,4,3]

Many answers are valid as long as the array becomes sorted.

⏱️ Time Complexity
O(n²)

Finding the maximum takes O(n) and we do it for each position.

📦 Space Complexity
O(1)

Ignoring the output list.

969. Pancake Sorting
❓ What is the question asking?

You are given an array.

You cannot swap elements directly.

You can only perform one operation:

Choose k

↓

Reverse arr[0...k-1]

Return the sequence of k values used to sort the array.

⚡ Optimal Approach
💡 Idea

Suppose

[3,2,4,1]

Goal:

Move the largest unsorted element to its correct position.

For every position from the end:

Find the largest element.
Bring it to the front (if not already).
Flip the whole unsorted part.
Largest element reaches its final position.
Repeat.
💻 Java Code
import java.util.*;

public class Main {

    public static List<Integer> pancakeSort(int[] arr) {

        List<Integer> ans = new ArrayList<>();

        int n = arr.length;

        for (int size = n; size > 1; size--) {

            // Find index of largest element
            int maxIndex = 0;

            for (int i = 1; i < size; i++) {
                if (arr[i] > arr[maxIndex]) {
                    maxIndex = i;
                }
            }

            // Already in correct position
            if (maxIndex == size - 1)
                continue;

            // Bring largest element to front
            flip(arr, maxIndex);
            ans.add(maxIndex + 1);

            // Move largest element to its correct position
            flip(arr, size - 1);
            ans.add(size);
        }

        return ans;
    }

    public static void flip(int[] arr, int end) {

        int start = 0;

        while (start < end) {

            int temp = arr[start];
            arr[start] = arr[end];
            arr[end] = temp;

            start++;
            end--;
        }
    }

    public static void main(String[] args) {

        int[] arr = {3, 2, 4, 1};

        System.out.println(pancakeSort(arr));

        System.out.println(Arrays.toString(arr));
    }
}
