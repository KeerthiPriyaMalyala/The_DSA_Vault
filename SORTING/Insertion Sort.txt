4. Insertion Sort
❓ What is the question asking?

Given an unsorted array, sort it in ascending order using the Insertion Sort algorithm.

⚡ Optimal Approach

Note: There is no separate Brute Force or Better approach. Insertion Sort itself is the standard algorithm.

💡 Idea

Imagine you're arranging playing cards in your hand.

The first card is already sorted.
Pick the next card (key).
Compare it with the sorted part on the left.
Shift all larger elements one position to the right.
Insert the key in its correct position.
Repeat until all elements are sorted.

👉 Remember: We shift elements, then insert the key. We don't keep swapping like Bubble Sort.

💻 Java Code
public class Main {

    static void insertionSort(int arr[]) {

        int n = arr.length;

        for (int i = 1; i < n; i++) {

            int key = arr[i];
            int j = i - 1;

            while (j >= 0 && arr[j] > key) {
                arr[j + 1] = arr[j];
                j--;
            }

            arr[j + 1] = key;
        }
    }

    public static void main(String[] args) {

        int arr[] = {5, 4, 1, 3, 2};

        insertionSort(arr);

        for (int num : arr)
            System.out.print(num + " ");
    }
}
▶️ Output
1 2 3 4 5
⏱️ Time Complexity
Best Case

O(n) ✅ (Already sorted)

Average Case

O(n²)

Worst Case

O(n²) (Reverse sorted array)

📦 Space Complexity

O(1)

Only a few extra variables (key and j) are used.

🧠 Key Points
✅ Builds the sorted array one element at a time.
✅ Uses shifting, not repeated swapping.
✅ Stable sorting algorithm.
✅ In-place sorting algorithm.
✅ Adaptive (very fast for nearly sorted arrays).
✅ Excellent for small arrays.

🌟 Interview Trick
Bubble Sort 🫧

👉 Swap adjacent elements until the largest reaches the end.

Selection Sort 🎯

👉 Find the minimum and place it at the beginning.

Insertion Sort 🃏

👉 Pick a key, shift larger elements, and insert the key in the correct position.

💖 These three are the foundation of sorting. Once you're comfortable with them, Merge Sort and Quick Sort will feel much easier.
