5. Recursive Insertion Sort
❓ What is the question asking?

Given an unsorted array, sort it in ascending order using Insertion Sort with Recursion instead of the outer loop.

⚡ Optimal Approach

Note: There is no separate Brute Force or Better approach. Recursive Insertion Sort itself is the standard recursive version.

💡 Idea

Normal Insertion Sort has an outer loop that inserts one element at a time into the sorted part.

In the recursive version:

Assume the first n-1 elements are sorted using recursion.
Insert the nth element into its correct position.

👉 The recursion replaces the outer loop, while the insertion (shifting) logic remains the same.

🧠 Example

Recursive Call (n = 1)
5

Already sorted.

Recursive Call (n = 2)

Insert 4 into:

5

Result:

4 5
Recursive Call (n = 3)

Insert 1 into:

4 5

Result:

1 4 5
Recursive Call (n = 4)

Insert 3 into:

1 4 5

Result:

1 3 4 5
Recursive Call (n = 5)

Insert 2 into:

Sorted 🎉

💻 Java Code
public class Main {

    static void insertionSort(int arr[], int n) {

        // Base Case
        if (n <= 1)
            return;

        // Sort first n-1 elements
        insertionSort(arr, n - 1);

        // Insert last element
        int key = arr[n - 1];
        int j = n - 2;

        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }

        arr[j + 1] = key;
    }

    public static void main(String[] args) {

        int arr[] = {5, 4, 1, 3, 2};

        insertionSort(arr, arr.length);

        for (int num : arr)
            System.out.print(num + " ");
    }
}
▶️ Output
1 2 3 4 5
⏱️ Time Complexity
Best Case

O(n) ✅ (Already sorted)

Average Case

O(n²)

Worst Case

O(n²)

📦 Space Complexity

O(n)

Reason:

Recursion uses the call stack, creating up to n recursive calls.
🧠 Key Points
✅ Same logic as Insertion Sort.
✅ Outer loop is replaced with recursion.
✅ Uses shifting, not swapping.
✅ Stable sorting algorithm.
✅ Adaptive for nearly sorted arrays.
❌ Uses extra recursion stack (O(n)).

🌟 Interview Trick
Recursive Bubble Sort ➜ After each recursive call, the largest element is fixed at the end.
Recursive Insertion Sort ➜ Before inserting, the first n-1 elements are already sorted, then insert the last element in the correct position.
