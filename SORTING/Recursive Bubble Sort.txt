3. Recursive Bubble Sort
❓ What is the question asking?

Given an unsorted array, sort it in ascending order using Bubble Sort with Recursion instead of the outer loop.

⚡ Optimal Approach

Note: There is no separate Brute Force or Better approach. Recursive Bubble Sort itself is the standard recursive version.

💡 Idea

The normal Bubble Sort has two loops:

Inner loop → Compares adjacent elements and pushes the largest element to the end.
Outer loop → Repeats the process for the remaining array.

In the recursive version:

The inner loop remains the same.
The outer loop is replaced by recursion.

Each recursive call sorts one less element because the last element is already in its correct position.

🧠 Example

Array:

5 4 1 3 2
First Call (n = 5)

After one pass:

4 1 3 2 5

5 is now in its correct position.

Second Call (n = 4)
1 3 2 4 5

4 is now fixed.

Third Call (n = 3)
1 2 3 4 5
Fourth Call (n = 2)

Already sorted.

Fifth Call (n = 1)

Stop (Base Case).

Sorted 🎉

💻 Java Code
public class Main {

    static void bubbleSort(int arr[], int n) {

        // Base Case
        if (n == 1)
            return;

        boolean swapped = false;

        // One Bubble Pass
        for (int i = 0; i < n - 1; i++) {

            if (arr[i] > arr[i + 1]) {

                int temp = arr[i];
                arr[i] = arr[i + 1];
                arr[i + 1] = temp;

                swapped = true;
            }
        }

        // Already Sorted
        if (!swapped)
            return;

        bubbleSort(arr, n - 1);
    }

    public static void main(String[] args) {

        int arr[] = {5, 4, 1, 3, 2};

        bubbleSort(arr, arr.length);

        for (int num : arr)
            System.out.print(num + " ");
    }
}
▶️ Output
1 2 3 4 5
⏱️ Time Complexity
Best Case

O(n) ✅ (Already sorted)

Average Case

O(n²)

Worst Case

O(n²)

📦 Space Complexity

O(n)

Reason:

Recursion uses the call stack, so there are up to n recursive calls.
🧠 Key Points
✅ Same logic as Bubble Sort.
✅ Outer loop is replaced with recursion.
✅ Inner loop remains unchanged.
✅ Stable sorting algorithm.
✅ Adaptive (with swapped optimization).
❌ Uses extra recursion stack (O(n) space).
🎯 Dry Run

Array:

3 2 1
Recursive Call	Array
n = 3	2 1 3
n = 2	1 2 3
n = 1	Stop ✅
🌟 Interview Tip

Remember this transformation:

Iterative Bubble Sort:

for (int i = n; i > 1; i--)

Recursive Bubble Sort:

bubbleSort(arr, n - 1);

The recursion simply replaces the outer loop.
