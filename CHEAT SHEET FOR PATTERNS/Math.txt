🌸 MATH MASTER CHEAT SHEET
🧠 First Rule

When you see a Math problem, ask these questions in order:

1️⃣ Can I solve it using digits?
2️⃣ Can I solve it using modulo (%)?
3️⃣ Can I solve it using division (/)?
4️⃣ Is there a mathematical formula?
5️⃣ Is there a number property?
6️⃣ Is there a simulation?
7️⃣ Will the number overflow?

These 7 questions solve almost every Math problem. ❤️
