🎯 When to use Dutch National Flag Algorithm?

Use it when the array contains only 3 different values/categories and you need to sort or partition them in one pass.

Think of this pattern whenever you see:

Only 3 types of elements
✅ Pattern 1: 0's, 1's and 2's ⭐⭐⭐⭐⭐
[2,0,1,2,1,0]

Sort them.

➡️ Dutch National Flag

✅ Pattern 2: Three Categories

Example

Negative
Zero
Positive

or

Medium
Large

Partition them.

📌 Interview Cheat Sheet
Question Pattern	Algorithm
Only 0,1,2	✅ Dutch National Flag
Three categories	✅ Dutch National Flag
< pivot, = pivot, > pivot	✅ Dutch National Flag
Many distinct numbers	❌ Normal Sorting
Two categories (0 & 1, Even & Odd, Positive & Negative)	✅ Two Pointers

⭐ Rule for interviews:

2 groups → Think Two Pointers.
3 groups → Think Dutch National Flag (low, mid, high).
Many values → Think sorting algorithms (Merge Sort, Quick Sort, etc.).

This simple rule will help you recognize the pattern within a few seconds during coding rounds. 💖
