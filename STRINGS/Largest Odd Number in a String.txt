🟡 Question: Largest Odd Number in a String

LeetCode 1903 – Largest Odd Number in a String

❓ What is the question asking?

You are given a numeric string num.

Return the largest-valued odd-numbered substring of num.

If no odd number exists, return an empty string "".

👉 Since we need the largest substring, we should keep the string starting from index 0 and remove characters only from the end until the last digit becomes odd.

Example 1
Input:
"52"

Output:
"5"

Explanation:

52 → Even ❌

Remove last digit

5 → Odd ✅
Example 2
Input:
"4206"

Output:
""

Explanation:

4 2 0 6

No odd digit exists.
Example 3
Input:
"35427"

Output:
"35427"

Already ends with an odd digit.

🪨 Brute Force Approach
💡 Idea

Generate every possible substring.

For every substring

Check if it is odd.
Keep the largest one.

This works but is very slow.

💻 Java Code
class Main {

    public static String largestOddNumber(String num) {

        String ans = "";

        for (int i = 0; i < num.length(); i++) {

            for (int j = i; j < num.length(); j++) {

                String sub = num.substring(i, j + 1);

                char last = sub.charAt(sub.length() - 1);

                if ((last - '0') % 2 == 1) {

                    if (sub.length() > ans.length()) {
                        ans = sub;
                    }
                }
            }
        }

        return ans;
    }

    public static void main(String[] args) {

        String num = "52";

        System.out.println(largestOddNumber(num));
    }
}
▶️ Output
5
⏱️ Time Complexity
O(N³)
O(N²) substrings
O(N) to create substring
📦 Space Complexity
O(N)
⚡ Optimal Approach
💡 Idea

An odd number always ends with an odd digit.

Odd digits are

1 3 5 7 9

Start from the last character.

If it is odd → return substring from 0 to that index.
Otherwise keep moving left.
If no odd digit is found → return "".

No need to check every substring.

💻 Java Code
class Main {

    public static String largestOddNumber(String num) {

        for (int i = num.length() - 1; i >= 0; i--) {

            char ch = num.charAt(i);

            if ((ch - '0') % 2 == 1) {
                return num.substring(0, i + 1);
            }
        }

        return "";
    }

    public static void main(String[] args) {

        String num = "35420";

        System.out.println(largestOddNumber(num));
    }
}

🧠 Interview Trick / Memory Trick
⭐ Remember
Largest Number

↓

Don't remove from front

↓

Remove only from end

↓

Find first odd digit from right

↓

Return substring(0, i+1)
🎯 Why Does This Work?

Suppose

35420

If we remove digits from the front,

5420

This is smaller than

354

To get the largest value, we should always keep the leftmost digits and only trim the suffix until the last digit is odd.

⭐ Revision in 15 Seconds
Start from last index

↓

Find first odd digit

↓

Return substring(0, i+1)

↓

If not found

Return ""

This is one of those interview questions where the optimal solution is much simpler than the brute force—the key observation is that only the last digit determines whether a number is odd. Once you spot that, the O(N) solution becomes very natural. 💖🚀
